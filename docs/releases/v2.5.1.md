# 组织罗盘 OrgCompass v2.5.1

v2.5.0 第三轮评审遗留的 7 项 HR 口径问题修正。`.orgproj` 文件格式版本不变（4），旧文件可直接打开。

## 口径修正
1. **继任未录入 = 未配置**：范围内没有任何继任人时，继任覆盖率显示「未配置」、状态为暂不判定，并计入数据完整度；不再按 0% 判预警。关键岗位已空缺且无近期可接继任人时，覆盖率再高也至少「关注」。
2. **岗位序列映射对齐**：默认映射覆盖岗位与编制页的全部序列（技术/产品/设计/运营/市场/职能/管理/销售/客服/门店/生产/仓储/护理/医疗/教学/法务/战略/专家）。销售、客服、门店、生产、仓储、护理按操作型；职能、管理按知识型；法务、战略、专家按专家型。未映射的序列不猜测，列入数据完整度。旧项目读取时补齐新默认项，用户自定义优先。
3. **可比职级值**：职级新增「可比职级值」（rank），跨序列（L/E）按实际资历比较倒挂/平级/压缩，调整职级列表顺序不再影响结论。默认职级表 rank = 编号（L3.1 与 E3.1 同为 3.1）；旧文件缺省时按编号推导，不写回。
4. **降本节省 = 管理溢价**：合并测算默认假设被合并的经理转为专业岗（不离岗），节省 = 本人成本 − 原团队最高专业岗成本；可在阈值设置中切换为「离岗」假设。任一成本缺失不给数字。
5. **场景决定总评**：降本增效计入管理幅度；快速扩张计入继任覆盖、空岗率、管理幅度（下限放宽）与新增的「管理者梯队」（管理岗近期可接后备人数 ÷ 管理岗数，去重；未录入继任或管理岗少于 5 个不判灯）。
6. **汇报链分位数**剔除顶层负责人（链长 0）。
7. **行业模板重建**：制造（工厂→车间→产线，孤立深链）、零售（大区→片区→门店，片区经理单点过宽）、医院（临床医学部→科室→病区，职级倒挂）、互联网（扁平知识型团队，研发组长层过窄）、教育（集团→校区，东校区校长空缺且无继任）。全部为显式汇报关系、真实中文姓名、带继任数据，越过小样本门槛；其余指标默认健康。

## 判读规则补充
- 管理幅度：同类管理者中最宽者超过关注上限时，类型灯至少「关注」（≥1.5 倍上限为「预警」），单点过宽不被中位数抹平。
- 汇报链：P90 健康但最长链超过关注上限时判「关注」（孤立深链）。
