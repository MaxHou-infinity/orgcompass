# OrgCompass v2.3.0

v2.3.0 定位为「排兵布阵可用化」：补齐人岗与评价数据的可信链路，整合已有看板，交付可直接使用的岗位缺口清单。

用户现在可以完成这样的过程：查看一个部门及其下级的岗位编制、实际占用与缺口 → 区分哪些人未套岗、哪些岗位超编、哪些评价未完成、哪些能力风险待复核 → 从汇总下钻到具体岗位、员工及评分依据 → 调整人岗关系或复核评价后保存重开仍能核对结果与历史 → 导出与界面一致的岗位缺口清单，作为招聘沟通底稿。

## 人岗事实一致性

- **岗位内超编归因**：岗位超额数量只在本岗位内判定，与其他岗位的人员增减、排序或层级展开无关。缺少可信入岗顺序或同时入岗跨越编制边界时，显示「岗位超额 N 人，具体人员需判断」，不任意指定个人。
- **任职关系贯通**：套岗、换岗、取消套岗、兼岗与任职记录在同一次工作区变更中完成，支持撤销重做；离岗后再入同岗创建新关系，不复活旧确认。
- **导入保护**：对已有人员、岗位或评价的场景，重新导入默认在新的场景执行，原场景及其关联数据完整保留；取消导入不产生任何变化。
- **评分导入身份**：工号与姓名分别建立索引，重号报歧义，明确工号不匹配时不退回同名，存在未解决歧义时整批不写入。

## 评估可信与复核闭环

- **同日修订**：对同一人、维度、评分角色和评估时点的纠错，新记录显式引用被修订记录，旧分保留；修订链终点才是有效记录。内容冲突且没有修订关系时标记「评分冲突待核对」，不按顺序任选。
- **评价完整度**：与能力灯号分开表达。应评维度按当前分类（干部 / 员工）确定，区分「模型未配置 / 未评 / 部分已评 x/y / 完整已评」。**部分已评即使已评维度全部达标，也不算完整达标。**
- **岗位适用性**：岗位评价绑定具体人岗关系；换岗后旧岗位评分不会自动成为新岗位结论，仅作历史可见并标注「适用性待复核」。
- **HRBP 校准**：可独立录入校准分，与上级原始分并列对照，不参与原始能力灯号与完整度分子；批次经办人与实际评分人分开留痕。
- **复核留痕**：人工确认与撤销分别记录复核人、时间、依据说明与关联岗位/评分，撤销后原确认事实仍可查；确认之后出现新评分时提示「待复核」，系统不自动撤销人工结论。

## 现状看板整合

- 胜任度看板提供统一的部门范围：任意层级下钻、祖先面包屑、「含下级 / 仅直属」切换。
- 组织指标、岗位缺口、评价完整度、能力风险与待复核项并列展示，各自独立口径，不合成「排兵布阵总分」。
- 支持未评、部分已评、能力风险、待复核筛选，并与人员详情、画布定位联动。
- 汇总与明细复用同一份派生结果，父子部门不重复累计；人数按真人去重，兼岗不产生第二个人；未入架构人员独立提示，不混入任何部门分母。

## 岗位缺口清单交付

- 从当前场景直接查看与导出，不要求先建立第二个场景。
- 字段包含场景、完整部门路径、岗位、职级带宽、岗位状态、编制配置状态、编制、主岗占用、兼岗关系数、待补人数、超额人数、成本估算状态、估算值与估算依据。
- **待补与超额分别求和**，净额只作补充，不以另一岗位超编抵消本岗位待补。
- 编制冻结、未配置编制（编制 0）与真实满编分别表达；找不到成本依据时显示「无法估算」并保持空值，不写成 0；部分岗位缺依据时总额标为「已知部分」并给出缺失岗位数。
- 界面与 Excel 消费同一份筛选结果；导出附带生成时间、范围与统计口径，默认不含个人姓名、工号、个人薪酬、评分或复核依据。
- 管理层报告补齐岗位明细，Excel 与界面一致。

## 数据与兼容

- `.orgproj` 数据格式升级为 **4**，保存任职关联、评价适用范围与修订关系、复核留痕字段；岗位扁平镜像在保存时与部门树保持一致。
- 旧格式文件沿用既有迁移链，不伪造到岗日期、确认人或评分依据；未知事实保持未知。
- 检测到高于当前支持的文件格式时拒绝载入与覆盖，原自动保存内容保留并可导出；首次写入格式 4 前先备份原始存储。
- **回退提示**：旧版应用无法完整读取格式 4，回退请使用升级前的文件或自动备份。

## 发布验证

- 自动化测试：32 个测试文件、507 项全部通过。
- TypeScript 类型检查与生产构建通过。
- ESLint：0 个错误；保留 3 个既有 React Fast Refresh 警告（`OrgChart.tsx`）。
- 用户侧 20 个真实场景验收通过，覆盖岗位操作、胜任度看板、维度配置、批量评估、健康度、场景对比、管理层报告、搜索、缩放、场景管理与岗位缺口清单。
- 规模回归：1000 名员工、52 个部门、6000 条评分下派生完整、去重正确、父子范围一致、缺口清单分列、序列化回读无损。
- 窄窗口回归：1440 / 900 / 560 三档宽度下新版界面无裁切、重叠或横向溢出。
- macOS 桌面构建通过（arm64，本地验证为 adhoc 签名，正式对外分发需另行公证）。

## 边界

- 本版不包含：AI 自动评价、自动定级、继任推荐、360 评价、行业基准、招聘审批与外部 ATS 集成、云端账号与遥测。
- 岗位缺口清单是编制缺口事实，不是已批准招聘需求。
- 能力灯号与复核只呈现可追溯依据，不自动输出调岗、晋升或淘汰结论。
