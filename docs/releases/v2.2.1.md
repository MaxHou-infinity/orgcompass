# OrgCompass v2.2.1

v2.2.1 是 v2.2.0 胜任度能力上线后的体验收敛版本。本版不扩展产品功能，集中修复实际使用中的交互、视觉、导出与大型组织稳定性问题。

## 体验改进

- 统一工作区、抽屉、弹窗和报告的视觉层级、留白、色彩与操作反馈。
- 优化窄窗口布局、工具栏收纳和画布可用空间，避免关键操作被遮挡。
- 完善弹窗焦点、键盘操作和可访问语义，减少连续操作中的断点。
- 调整搜索、组织健康度、诊断报告、场景对比与胜任度界面的信息层级和状态表达。
- 修正刷新画布可能使用旧导入数据覆盖当前编辑结果的问题。

## 稳定性修复

- 修复现代 CSS 色彩函数导致 `html2canvas` 导出 PNG 失败的问题，并统一画布导出处理。
- 自动保存改用压缩存储，同时兼容旧版未压缩数据，解决大型组织与大量胜任度记录触发存储配额后“保存失败”的问题。
- 改进 PNG 导出失败信息，便于定位真实原因。

## 发布验证

- 自动化测试：406 项全部通过。
- TypeScript 与生产构建通过。
- ESLint：0 个错误；保留 3 个既有 React Fast Refresh 警告。
- 桌面原生保存：PNG、Excel、`.orgproj` 均通过 macOS 原生保存对话框落盘并校验文件内容。
- 大型组织：1000 名员工、52 个部门、6000 条胜任度记录；导入、自动保存、重启恢复、搜索、健康度、诊断报告和三种导出全部通过。
- 大型组织实测导出：PNG `21524 × 1662`、Excel `1001/53` 行、`.orgproj` 回读保持 1000/52/6000 数据完整。
