# 组织罗盘 OrgCompass v2.5.0

本版让组织诊断更贴近实际汇报关系和业务阶段，并改善桌面端加载与方案对比体验。

## 诊断与数据口径

- **汇报线覆盖率**：异常人员单独列出；默认覆盖率 80%–95% 提醒数据不完整，低于 80% 暂停管理幅度判灯。部门子树独立检查，小样本规则优先。
- **职能幅度基准**：按直属下属岗位族区分操作型、知识型、专家型；提供三阶段×三类型的九组可调范围、岗位族映射与部门默认类型。每类至少三名管理者才参与总评。
- **人员汇报链与职级**：展示 P50/P90、最长链、完整人名路径、倒挂与平级清单；部门层级仅参考，职级按用户配置顺序比较。
- **关键岗位与继任**：支持人工指定关键岗位、继任人和准备度，新增覆盖率、单点风险与继任人集中提示，支持 Excel 模板和整批导入校验。不自动推断接班人。
- **五种业务场景**：常态运营、快速扩张、降本增效、并购整合、新业务孵化；场景及阈值随项目保存，所有方案共用。建议附数据依据和预期影响；成本估算只在有数据与明确条件时提供。
- 统一管理者定义，合并同人多正职负荷；未设置负责人的部门向上寻找最近的正职负责人；未知数据不再当作黄灯。

## 体验与示例

- 健康度、胜任度、场景对比、诊断报告、职级管理、岗位与编制改为懒加载，附加载骨架和失败说明。主入口约 233 KB（未 gzip）。
- 单方案时，对比按钮支持悬停/键盘说明及一键复制并切换到副本；复制保存失败不会产生虚假副本。
- 增加适配视图和窄屏侧栏收起，改善空数据和报告文案。
- 恢复制造、医院的较深部门形态及零售门店网络；示例为合成教学数据，预置继任未配置与待招岗位，不把推断汇报写成原始事实。

## 升级与边界

- `.orgproj` 继续使用格式 4；新版可读取旧项目，并保存新增诊断设置与继任字段。建议升级前保留项目备份。
- 开发与测试不再支持 Node 20；要求 `^22.22.2`、`^24.15.0` 或 `>=26.0.0`。桌面安装包使用者无需安装 Node。
- 阈值是可调整的产品规则，不是行业标准；管理者成本占比仅参考，不凭空判灯。人员调整和节省收益是待评审的条件测算，不会自动执行。
- 在途 offer、待入职/待离职和 FTE 折算尚未纳入。

## 验证

- 本地 Node 22：74 个测试文件、879 项测试全部通过；类型检查、lint、覆盖率门槛、生产构建及拆包门禁通过。
- 本地 macOS 桌面测试包实际打开六个拆分视图，使用内嵌资源；独立测试数据未覆盖正式应用。
- macOS Apple Silicon 与 Windows 安装包由本标签对应的 GitHub Actions 构建，随 Release 提供。

首次安装指引见仓库 README。macOS 安装包适用于 Apple Silicon；Windows 提供安装程序。
